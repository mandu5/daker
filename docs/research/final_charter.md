## 0. 한 장 결론

**베이스는 f3(카이론/CHIRON, 분야3)이다.** 심사위원 3인 중 2인(domain 70점 1위, peer 69점 1위)이 f3를 선택했고, 3인째(eng)도 f2와 0.5점 차 사실상 동률로 2위에 놨다. 그러나 **f3를 그대로 내면 진다.** 세 심사위원이 f3에 겨눈 kill shot이 정확히 같은 곳을 찌른다 — *"측정된 숫자가 하나도 없고, 시스템의 과학적 알맹이인 구조 룰 40개가 검증된 적이 없으며, 그 조항 대부분은 이미 프로토콜 템플릿에 있는 보일러플레이트다."*

**그래서 오늘 그 세 개를 한꺼번에 죽였다.** 본 문서를 쓰는 동안 실측한 결과:

- TrialBench(GitHub, clone 실측 성공)의 `trial-approval-forecasting` / `serious-adverse-event-forecasting` 계열에 **`smiless`(SMILES) 컬럼과 `eligibility/criteria/textblock`(실제 프로토콜 선정·제외기준 전문)이 같은 행에 함께 존재한다.** Phase 2 approval 학습분할 하나만으로 **RDKit 파싱 성공 + 기준 텍스트 보유 = 5,208건**. 전 태스크·전 상(phase) 합치면 1만 건대. **즉 "구조 → 실제 프로토콜 조항"의 정답 라벨을 예선 오프라인에서 수천 건 규모로 확보할 수 있다.** eng 심사위원이 지적한 "S2C의 차별점이 네트워크 차단 구간에 있다"는 전제가 무너졌다.
- 그 5,208건에서 구조 알림과 실제 조항 출현의 연관을 Fisher 정확검정으로 실측했다(본 문서 §5.1 표). 염기성 아민∧cLogP≥3.7 → CYP/DDI 조항 lift 1.85 (p=1.3e-9), 반응성 대사체 알림 → 간기능 조항 lift 1.18 (p=1.6e-9), 카복실산 → CYP/DDI 조항 lift 0.37 (p=8.6e-9, **음의 방향**). **domain이 "1990년대 구식 휴리스틱"이라 부른 룰이 실제 프로토콜 텍스트에서 유의한 신호를 낸다는 것을, 우리가 오늘 직접 측정했다.**
- 동시에 **domain의 지적도 맞았다는 것을 우리가 먼저 증명했다.** 간기능 조항 기저율 52.1%, 피임 조항 47.8% = 사실상 전 프로토콜 보일러플레이트. 반면 QT/ECG 18.4%, CYP/DDI 10.9% = 보편적이지 않다. **그래서 우리는 조항을 "템플릿 조항"과 "분자 특이 조항"으로 데이터에 근거해 분리하고, 후자에서만 가치를 주장한다.** 그리고 종양/비종양 층화 시 thio→간기능 lift가 1.18→1.02(종양 내 소멸)로 무너지는 것도 함께 보고한다 — 적응증 교락이 실재하며 우리 평가 설계가 그것을 통제해야 한다는 증거다.

**한 문장:** f3의 "구매자와 예산 항목이 실재하는" 포지션을 유지하되, f2의 유일한 자산인 *측정 규율*(신뢰도 게이팅·기권·Δ\* 특이성 검정·false veto 병기)을 이식하고, **헤드라인 지표를 "템플릿 대비 증분"으로 재정의**하여 세 심사위원의 kill shot을 전부 우리 주지표로 전환한다.

### 1.2 이식 목록 (무엇을, 왜, 어디에)

**f2 시금석 → 이식 4건 (최우선)**

1. **보정된 선택적 발행 (calibrated selective issuance).** f2가 MoleculeACE에서 실증한 T = |Δ|/(σ+ε)×AD 구조를 조항 도메인으로 번안. 신뢰도 미달 조항은 발행하지 않고 기권. → §4.2 MARKER·§4.6 LEDGER. **f3의 최대 결손인 "측정치 없음"을 메우는 핵심.**
2. **Δ\* 구조 특이성 검정(score-matched decoy).** 벌크 물성은 매칭하고 구조 알림만 파괴한 decoy 분자에서 같은 조항이 제안되면 그 조항은 구조 유래가 아니라 템플릿/물성 산물 → 기각. → §4.5 ADVERSARY. **domain의 최대 kill shot("보일러플레이트")에 대한 기계적 반박 장치.**
3. **false veto율 / 정상 대조군 필수 병기.** 경고를 내면 안 되는 케이스를 경고 케이스와 같은 수로 넣고 precision@k와 FAR를 항상 나란히 보고. → §5.4 E3.
4. **CMC hard veto.** 조항 유형에 "CMC·공정 유래 임상 조항"(키랄 분리 부담, 유전독성 불순물 스펙, 조제·보관 조항)을 추가하고 롤론티스 사례를 근거로 인용. → §4.4. domain이 "4개 중 유일한 pharma 현장 감각"이라 평가한 요소.

**f1 널스페이스 → 이식 3건**

5. **단일 주지표 승격 + 조건부 주장.** `FOR_safety`(안전성 조항을 불필요로 판정한 비율)를 주지표로 올리고, **2% 초과 시 절감 주장 자체를 철회한다고 제안서에 명기**. f1의 "FKR>5%면 시간 절감 주장 철회" 형식 그대로.
6. **검정력 게이트.** "이 표본수로는 요구 효과크기를 탐지할 수 없다" → 판정 불가 강제 + 필요 N 재계산. → §4.4 ACTUARY. domain 평가: "구조 룰 40개보다 규제 심사위원에게 훨씬 강하게 읽힌다."
7. **평가 한계를 평가 섹션 첫머리에 배치하는 순서 전략** + 기존 평가가 부적절한 근거 4숫자(BixBench 17% / CiteME 4.2~18.5% vs 69.7% / AgentClinic 1/10 / PLINDER 누출) 선공.

**f4 다림줄 → 이식 3건**

8. **provenance를 자료형으로 강제.** `provenance.kind ∈ {computed, guideline, corpus, user_input}`이고 `computed`가 아닌데 `url`/`span_id`가 없으면 시스템이 자동으로 `unverified` 격리 + 판정 가중치 0. → §4.6·§10. **근거 코퍼스가 30문서로 좁다는 약점을 "범위가 좁은 것이지 근거가 없는 것이 아니다"로 전환.**
9. **LLM 없는 규칙 엔진 베이스라인(B-RULE, 0 토큰)** 정식 편성 + 증분 정직 보고. peer의 "1980년대 전문가 시스템 아니냐" 공격에 대한 유일한 방어.
10. **축소 순서(descope order) 사전 확정 + 절대 축소 금지 4항목 명기.** → §6.4.

**f4의 단일 수직선 은유는 이름으로 흡수했다** (먹줄). f4의 역방향 컴파일(TPP→물성창)은 **채택하지 않는다** — 세 심사위원 중 둘이 "약동학적으로 근거 없는 과대주장"으로 지목했고, 그 판단이 옳다.

| K11 | **"구성적 정답셋은 자기 코드가 만든 위반을 자기 코드로 검사하는 순환. 누출 0인 대신 타당도 0."** (eng·peer, f4 대상 → decoy 사용 시 상속 위험) | **decoy는 정답원이 아니라 귀속(attribution) 도구**임을 명시. E1의 정답은 **실제 임상시험 프로토콜의 선정·제외기준 텍스트**(TrialBench)이고, decoy는 "이 조항이 구조 때문인가 물성 때문인가"를 분리하는 대조군으로만 쓴다. 이 구분을 제안서 평가 섹션에 별도 박스로 넣는다. |
| K12 | **"N=60에서 FKR≤5%는 통계적으로 검정 불가능."** (domain·peer, f1 대상 → 상속 위험) | 해당 없음 — E1 규모가 조항 유형 12종 × 수천 시험 = **셀 수 만 단위**. 단 조항 유형별로는 작아질 수 있으므로 **모든 지표에 Wilson 95% CI 병기**, 희소 조항(광독성 base rate 0.5%)은 "예선 판정 불가"로 명시 제외. |

## 3. 문제 정의

### 3.1 지점과 문장

**지점:** 비임상 종료 ~ IND 제출 ~ 1/2상 프로토콜 확정.
**사용자:** 국내 중소 바이오텍의 RA/임상개발 담당자 1~2명 (AI 전담 인력 0명, 폐쇄망 환경).

**40자 문제 문장(1쪽 굵게):**
> **"프로토콜 조항이 분자 구조를 반영하지 않아, 나중에 돈으로 고친다."**

**1쪽 훅 질문(peer 심사위원 권고 이식):**
> **"이 프로토콜의 조항 중, 이 분자 때문에 들어간 것은 몇 개입니까?"**
> 340개 문서가 "우리 에이전트가 무엇을 만들었는가"를 자랑할 때, 심사위원이 자기 회사 프로토콜을 떠올리게 만드는 질문 하나.

### 3.2 정량 근거

**[검증됨 · 1차 출처]**
- 실질적 프로토콜 수정 1건의 직접비 중앙값 **2상 US$141,000 / 3상 US$535,000** (Tufts CSDD + 제약사·CRO 15개사, 836개 프로토콜에서 발생률·136건에서 영향·52개 프로토콜에서 원가 산출). Therapeutic Innovation & Regulatory Science. https://link.springer.com/article/10.1177/2168479016632271
- 국내 임상 1상→품목허가 성공률 **3.6~4.8%**, 미국 임상 성공률 **7.9%**, **30%가 2상에서 중단**. 한국보건산업진흥원. https://www.khidi.or.kr/board/view?linkId=48854861&menuId=MENU01816
- IND 자료 미비 시 **30일 내 보완 요청**, 보완자료 부적정·기한 초과 시 반려. 「의약품 임상시험 계획 승인에 관한 규정」 제출자료 목록. https://nedrug.mfds.go.kr/cntnts/17
- **보완 사유별 통계는 공개 자료가 없다. 발생률을 수치화하지 않는다.** 주장 범위는 "보완 1회 회피 = 최소 30일 개시 지연 회피"까지.

**[검증됨 · 인력난]**
- "바이오 성장 속 RA 인력 하늘의 별따기", **대형 제약사보다 중소 바이오기업이 훨씬 크게 체감**. https://www.medicaltimes.com/Main/News/NewsView.html?ID=1140186
- "글로벌 빅파마는 회사마다 임상약리 전문가 100명 이상 + 동급 규모 PK/PD 모델링 그룹" vs 국내 부족. http://www.hitnews.co.kr/news/articleView.html?idxno=34260
- 임상시험 기관 **59%가 적격환자 확보 차질**, 응답자 **52%가 의뢰환자 중 최소 20%가 공식 선별검사 전 부적격**. https://www.kpanews.co.kr/news/articleView.html?idxno=538627

**[우리 실측 · 2026-07-26, 오프라인, TrialBench Phase 2 approval 학습분할 n=5,208]**
- 실제 프로토콜 조항 기저율: 간기능 **52.1%**, 피임 **47.8%**, QT/ECG **18.4%**, CYP/DDI **10.9%**, 광독성 **0.5%**.

**[추정 · 산출 논리 공개]**
2상 프로토콜 1건 = 선정·제외기준 20~40개 + 모니터링·중단규칙·병용·통계 조항 → 조항 총량 200~400개. 조항당 "규제 근거 확인 + 이 분자에 필요한지 판단" 3분 가정 → **10~20시간/검토 라운드**, 라운드 3~5회. 이 수치는 공개 통계가 아닌 우리 추정이며 산출식을 그대로 노출한다. 본선 W3에서 3인 사용자 스터디로 실측 대체.

### 3.3 왜 LLM 단독으로 안 되는가 / 왜 기존 자동화로 안 되는가

- 프론티어 모델의 실제 계산생물 워크플로 open-answer 정확도 **17%** (BixBench, arXiv:2503.00096). 동일 문항을 순차 의사결정 형식으로 바꾸면 정확도 **원래의 1/10 미만**으로 붕괴 (AgentClinic, arXiv:2405.07960). 인용 출처 지목은 LM **4.2~18.5%** vs 인간 **69.7%**, 검색 가능한 에이전트도 35.3% (CiteME, arXiv:2407.12861). → **숫자와 판정을 LLM 손에서 빼앗는 구조가 요구된다.**
- TrialGPT(Nat Commun 2024)는 환자↔시험 매칭이지 설계가 아니다. AMEND++(arXiv:2601.06300)는 "수정될 것이다"라는 이진 예측 벤치마크이지 어느 조항을 무엇으로 바꿀지 답하지 않는다. **어떤 공개 시스템도 분자 구조에서 조항을 연역하지 않는다.**

### 3.4 왜 지금인가

- 식약처 **2026년부터 AI 심사 도입**(허가자료 요약·검토서 초안, 신약 허가 240일 목표). https://www.mfds.go.kr/files/upload/etc/2026_mfds_1.pdf
- 식약처 「의약품 개발 시 AI 활용 안내서」 https://www.mfds.go.kr/brd/m_218/view.do?seq=33589 , 세계 최초 「생성형 AI 의료기기 허가·심사 가이드라인」 https://www.mfds.go.kr/brd/m_1060/view.do?seq=15628
- FDA 2025-01 draft: **Context of Use + model risk = model influence × decision consequence** 기반 7단계 credibility assessment. https://www.fda.gov/regulatory-information/search-fda-guidance-documents/considerations-use-artificial-intelligence-support-regulatory-decision-making-drug-and-biological
- ICH E6(R3) GCP 2025-01 Step 4 최종. https://database.ich.org/sites/default/files/ICH_E6(R3)_Step4_FinalGuideline_2025_0106.pdf
- **결정적 공백:** 위 프레임은 전부 결정론적 "모델"을 전제한다. 매 실행마다 도구 호출 경로가 달라지는 **비결정적 멀티에이전트의 COU 정의와 재현성 입증은 규정 공백**이다. 먹줄은 그 공백을 문서가 아니라 실물(COU 카드 + 감사 DAG + DPR 실측치)로 채운다.
- 그리고 **라벨이 지금 생겼다.** TrialBench(Nature Sci Data 2025)가 SMILES와 실제 선정·제외기준 원문을 같은 행에 담아 GitHub에 공개했다. 이것이 없었으면 구조→조항 가설을 채점할 방법 자체가 없었다.

## 4. 멀티에이전트 아키텍처 최종안

### 4.0 설계 원리 3개 (다이어그램에 색으로 표시)

- **P1 결정론 코어 / 확률론 주변부.** 모든 수치·구조 판정은 100% 결정론 도구(RDKit, 규칙엔진, scipy)가 낸다. LLM은 텍스트→구조 추출·모순 탐지·서술만. 다이어그램에서 **결정론=청색 실선 / LLM=회색 점선**. LLM이 숫자를 만들 물리적 경로가 없음을 한 장으로 증명.
- **P2 템플릿 분리(Template Separation).** 모든 조항은 발행 시점에 `template_baseline` / `molecule_specific` 중 하나로 라벨된다. **가치 주장은 후자에서만 한다.**
- **P3 선택적 발행(Selective Issuance).** 신뢰도 미달·구조 귀속 미입증 조항은 발행하지 않고 기권한다. 기권율과 risk-coverage 곡선을 시스템이 스스로 보고한다.

### 4.1 전체 흐름 (먹줄 다이어그램: 하나의 수직선 + 되돌아가는 화살표 4개)

```
입력: SMILES + 비임상 요약(종별 NOAEL·노출·표적장기) + 적응증 + 상(phase) + 관할(식약처/FDA)
  │
  ▼ [청색·결정론]
① MARKER  구조 → 리스크 플래그 + 각 플래그의 신뢰도(σ, AD)
  │           └─ 모달리티 게이트: 항체·세포·핵산 → 소분자 룰 비활성화, 범위 외 선언
  ▼
② SCRIBE  리스크 × (상, 적응증) → 조항 후보
  │           └─ 각 후보에 template_baseline 확률 p_base 부착 → 증분 Δ 산출
  │           └─ 4-튜플로만 발행: (근거 span, 유발 리스크, 봉인된 반증 조건, 신뢰도)
  ▼
③ ACTUARY 용량·검정력·모집가능성 [청색·결정론]
  │           NOAEL→HED→SF10→MRSD / 3+3 vs BLRM 몬테카를로
  │           검정력 게이트: 요구 효과크기 탐지 불가 → 판정 불가 + 필요 N 제시
  │           모집 게이트: 이 제외기준이 국내 등록 가능 인구를 몇 % 깎는가
  ▼
④ ADVERSARY 3중 반증 [청색·결정론]
  │   R1 근거 반증  : 인용된 가이드라인 원문 span에 그 요구가 실재하는가
  │   R2 귀속 반증  : Δ*(c) = Δ(c) − max(0, mean_decoy Δ) ≤ 0 → 구조 유래 아님, 기각
  │   R3 실행 반증  : 모집 인구 감소율 > 임계 → 기각하고 대안 요구
  ▼
⑤ LEDGER  선택적 발행 · 예산 · 감사 [청색 + 회색 혼합]
      T(c) ≥ τ        → 발행(advance)
      τ_low ≤ T < τ   → 사람 검토(escalate)
      T < τ_low ∨ Δ*≤0 → 기권(abstain)
      산출: Go/No-Go 조항표 + COU 카드 + 감사 DAG + 재현성 봉인(seed/버전/해시)

되돌아가는 화살표
 A1 ADVERSARY R1 기각 → SCRIBE 재기안 (최대 3회, 이후 기권)
 A2 ADVERSARY R2 기각 → MARKER 리스크 등급 하향 + 룰 가중치 국소 재보정 (Case Bank 영속화)
 A3 ADVERSARY R3 기각 → ACTUARY 회귀 (제외기준 대신 용량 상한·모니터링 빈도로 대체 탐색)
 A4 LEDGER 기권율 > 0.7 또는 동일 reason_code ≥ k → 사람에게 계약 개정 요청 (자동 완화 금지)
```

### 4.2 ① MARKER (표기관)

| 항목 | 내용 |
|---|---|
| 입력 | SMILES 리스트, 모달리티, 비임상 요약 |
| 출력 | `RiskFlag[]` = {risk_id, 근거 도구출력, 등급, σ(룰 앙상블 불일치), AD(적용범위 근접도), provenance} |

### 4.3 ② SCRIBE (기안관)

조항 유형 **12종**을 발행한다. 오늘 실측 기저율에 따라 두 군으로 분리:

| 군 | 조항 유형 | 예선 실측 기저율 |
|---|---|---|
| **T(템플릿)** | 간기능 검사치 제외·모니터링 / 가임 남녀 피임 요구 / 동의서 서식 정합 | 52.1% / 47.8% / — |
| **M(분자 특이 후보)** | QT·ECG 모니터링 및 중단규칙 / CYP 병용 제외·DDI 시험 / 특별 관심 이상반응 / 식이·자외선 생활 제한 / 용량 증량·DLT 정의 / 감량·중단 규칙 | 18.4% / 10.9% / — / 0.5% / — / — |
| **C(CMC 유래, f2 이식)** | 키랄 분리 부담 / 유전독성 불순물 스펙 / 조제·보관·안정성 유래 조항 | 본선 |

- 각 조항은 **반드시 4-튜플**로만 발행: `(evidence_span, trigger_risk_id, sealed_falsifier_hash, trust_score)`. 반증 조건이 비어 있으면 발행 자체가 거부된다.
- 각 조항에 `p_base(c | phase, indication_group)` = B-TPL 기저 확률이 자동 부착되고, 증분 `Δ(c) = p_hat − p_base`가 계산된다.
- 광독성처럼 기저율 0.5% 미만인 조항은 **예선에서 "판정 불가"로 명시 제외**(검정력 부족을 우리가 먼저 선언).

**LLM이 담당하는 지점(회색 점선) — 여기만이다:**
(a) 자유형 비임상 요약·프로토콜 텍스트 → 구조화 입력 추출
(b) 조항 간 내부 모순 탐지(프로토콜 ↔ ICF ↔ 중단규칙 ↔ 방문일정의 투여량·빈도 불일치)
(c) 상충(FDA vs 식약처) 발견 시 상충 카드 서술
각각을 ablation으로 분리 측정한다.

### 4.4 ③ ACTUARY (계량관)

- **개시용량:** NOAEL → HED(체표면적 환산) → 안전계수 10 → MRSD, 필요 시 MABEL. 근거: FDA 2005 MRSD 가이던스. 모든 숫자에 산출식 + 가이드라인 근거 문자열 결박. 검증: 공개 프로토콜 3건의 MRSD 역산 일치.
- **증량 스킴:** 3+3 vs BLRM/mTPI 몬테카를로(scipy) → DLT 오판 확률·기대 코호트 수·기대 과다투여 대상자 수.
- **검정력 게이트(f1 이식):** 제안 표본수로 요구 효과크기 탐지 불가 → **조항 판정을 내지 않고 기권 + 필요 N 재계산 제시**(statsmodels). "이 설계로는 아무것도 알 수 없다"를 말할 수 있게 한다.
- **모집 게이트:** 각 제외기준이 국내 등록 가능 인구를 몇 % 깎는지 공개 유병률·검사치 분포 가정으로 근사. 감소율 > 40% → HITL 강제.
- **CMC 거부권(f2 이식):** 유전독성 불순물 경보 모티프·키랄 부담은 **우회 불가 hard veto**. 근거: 롤론티스 CMC 자진취하 사례.

### 4.5 ④ ADVERSARY (반증관) — 시스템의 알고리즘적 심장

**Δ\* 구조 귀속 검정 (f2의 score-matched decoy를 규제 도메인으로 번안)**

후보 조항 c, 분자 m, 맥락 (phase p, indication d)에 대해:

```
p_base(c | p,d)   = 템플릿 기저 확률 (B-TPL)
p̂(c | m,p,d)      = 우리 모델 확률
Δ(c)              = p̂ − p_base                                  … 템플릿 증분
D(m)              = decoy 집합: MW·cLogP·TPSA·HBD·고리수는 매칭,
                    설계가 책임진다고 주장한 구조 알림만 파괴 (RDKit RWMol)
Δ*(c)             = Δ(c) − max(0, mean_{m'∈D(m)} [p̂(c|m',p,d) − p_base(c|p,d)])
```

**Δ\*(c) ≤ 0 이면 그 조항은 구조 유래가 아니라 물성·템플릿의 산물이므로 기각한다.**
→ domain의 "그건 이미 보일러플레이트다"에 대한 기계적 반박이자, 우리 시스템이 스스로에게 거는 음성 대조군.
→ **중요:** decoy는 정답원이 아니다. 정답은 실제 프로토콜 텍스트(E1)다. decoy는 귀속 분리 도구다. (f4가 받은 순환 비판을 구조적으로 회피)

**R1 근거 반증:** 인용 가이드라인 원문 span 부재 → 기각. span에 문서 위계 메타데이터(본문 > 부록 > Q&A) 부여, **가장 약한 근거가 조항 등급의 상한을 결정**.
**R3 실행가능성 반증:** 모집 인구 감소율 임계 초과 → 기각 + ACTUARY 회귀.
**경고 인플레이션 감시:** 프로토콜당 경고 예산 k(기본 5). 발행 경고 수 / 평균 등급 / 조항 유형 편중도를 감시, 초과 시 k 축소 후 SCRIBE 재실행. **precision@k와 alert-per-protocol을 항상 함께 보고** → recall만 올리는 게이밍이 보상되지 않는다.

### 4.6 ⑤ LEDGER (원장관)

**신뢰도와 발행 규칙**

```
T(c) = Δ*(c) / (σ(c) + ε) × AD(m)

발행 규칙:
   T(c) ≥ τ                → advance   (조항 발행)
   τ_low ≤ T(c) < τ        → escalate  (사람 검토)
   T(c) < τ_low  또는 Δ*≤0 → abstain   (기권, 발행하지 않음)

τ 캘리브레이션: 홀드아웃에서 목표 조항 정밀도(0.85)를 만족하는 최소 τ.
                isotonic 보정 후 ECE 보고.
```

**정지·수렴 조건(부등식)**
라운드 r, 미해결 조항 U_r, 경고 플래그 F_r, 개선량 Δ_r = |반증 통과 조항|_r − |…|_{r−1}, 예산 B.
> 정지 ⇔ (|U_r| = 0 ∧ F_r = 0) ∨ (Σ_{i=r−2}^{r} Δ_i < ε) ∨ (B_used/B_total ≥ 0.8)

**HITL 강제 에스컬레이션(조건문)**
> IF (안전성 조항의 T < τ) OR (모집 인구 감소율 > 40%) OR (FDA·식약처 근거 상충) OR (모달리티 범위 외) OR (재기안 3회 실패) OR (검정력 게이트 발동)
> THEN `human_review_required` 블록으로 승격, 결정 보류.

**AI는 자기 합격 기준을 낮출 수 없다.** kill criteria 완화는 사람의 서명 없이 불가능하며 원장에 차분이 기록된다. ADVERSARY의 유전독성·위험시약 hard veto는 사람도 우회 불가.

**provenance 자료형 강제 (f4 이식)**

```json
{"clause_id":"EX-014","type":"exclusion_criterion","clause_class":"molecule_specific",
 "text":"QT 연장을 유발하는 병용약 투여 중인 대상자",
 "trigger_risk":["R-hERG-01"],

```

> `provenance.kind`가 `computed`가 아닌데 `url`/`span_id`가 없으면 **시스템이 자동으로 `unverified` 격리**하고 판정 가중치를 0으로 만든다. 연구윤리를 문단이 아니라 자료형으로 답하는 지점이다.

**Case Bank:** 기각 조항 + reason_code + 당시 근거 상태를 append-only 저장, 다음 사이클 SCRIBE 프롬프트·MARKER 룰 가중치(**전역이 아니라 스캐폴드 국소**)에 재주입. 측정: 동일 reason_code 재기각률의 라운드별 감소.

**산출물 3종:** ① Go/No-Go 조항표(발행/기권/에스컬레이션 + reason_code) ② **에이전트용 COU 카드**(사용 목적, 조항별 criticality = model_influence × decision_consequence, 도구·버전·시드, DAG 해시, 인간 검토 필수 지점) ③ **재현성 봉인**(동일 시드 3회 실행 해시 일치 = DPR).

> **이 표가 제안서에서 가장 정직하고 가장 강한 표다.** 우리 룰 중 일부는 적응증 층화 후 무너진다. 그것을 우리가 먼저 측정해 보고하고, **층화·Δ\* 귀속 검정을 평가 프로토콜의 필수 요소로 만든 이유**로 제시한다. domain 심사위원의 "당신 룰은 검증된 적 없다"에 대한 답이 "검증했고, 절반은 떨어졌다"가 된다.

**지표 (수식)**

```
ΔP@C   = Precision(발행 조항 | 커버리지 C)  −  Precision(B-TPL 상위 동일 개수)      … 헤드라인
ΔAUPRC = AUPRC(우리) − AUPRC(B-TPL)                                              … 층화·조항유형별
AURC   = ∫ risk(coverage) d(coverage)                                            … risk-coverage 하 면적
FOR_safety = |{안전성 조항 c : 실제 프로토콜에 존재 ∧ 우리 판정 = "불필요"}| / |{안전성 조항 c : 실제 존재}|
             ★ 주지표. 목표 ≤ 2%. 초과 시 절감 주장 철회를 제안서에 명기.
             기권은 분자에 포함하지 않음(기권은 커버리지로 별도 보고).
Rule Adoption Rate = |채택 룰| / |초기 후보 룰|                                     … 정직성 지표
ECE, Brier                                                                       … 캘리브레이션
```
모든 지표에 **Wilson 95% CI 병기**. 조항 유형별·적응증군별로 층화 보고.

**폴백(우선순위 확정)**
1순위: 위 그대로. 2순위(기준텍스트 라벨러 κ<0.6): 조항 유형을 QT/ECG·CYP/DDI·간기능 3종으로 축소하고 라벨러 재작성. 3순위(라벨링 자체 실패): 태스크를 **"구조 플래그 → SAE 발생 라벨(Y/N) 예측"**으로 전환 — TrialBench `serious-adverse-event-forecasting/*/train_y.csv`에 `serious_adverse_rate` + `Y/N`이 존재함을 실측 확인.

### 5.2 E2 — DECOY (구조 귀속 검정) · 오프라인 100%

- E1의 각 시험 분자 m에 대해 벌크 물성 매칭 decoy K=8개 생성(RDKit RWMol; 구조 알림만 파괴, MW±10%·cLogP±0.5·TPSA±15·고리수 동일).
- 조항별 Δ\* 분포 산출. **Δ\* > 0인 조항 비율 = "구조 귀속률"** 을 조항 유형별로 보고.
- 지표: Attribution Rate, Δ\* 분포의 부트스트랩 CI, Δ\*≤0으로 기각된 조항 수.
- **명시:** decoy는 정답원이 아니라 귀속 도구다(K11 방어).

### 5.3 E3 — NULL (음성 대조·기권·상충) · 자체 제작, 예선 60~80건

| 서브셋 | 구성 | 정답 행동 | 지표 |
|---|---|---|---|
| (a) 깨끗 20건 | 구조 알림 0 + 조항 완비 프로토콜 | 경고 0 | **FAR** |
| (b) 중복 15건 | 리스크 실재하나 조항이 이미 존재 | 재제안 금지 | **Redundancy Rate** |
| (c) 근거부재 15건 | 어떤 가이드라인에도 근거 없는 리스크 | **기권** | **Abstention Recall** |
| (d) 상충 10건 | FDA vs 식약처 요구 상이 | HITL 에스컬레이션 | **Escalation Precision** |
| (e) 범위외 10건 | 항체·세포·ASO 입력 | 범위 외 자동 선언 | **Modality Gate Recall** |
| (f) 검정력 함정 10건 | 요구 효과크기 대비 N 부족 | 기권 + 필요 N 제시 | **Power Gate Recall** |

> **(a)와 (b)는 f2의 "정상 대조군" 이식이다.** 이것 없이 recall만 보고하면 "전부 경고하는 시스템"이 만점을 받는다. **precision@5와 FAR를 항상 나란히 보고한다.**

### 5.4 E4 — AUDIT (감사·재현성·비용) · 오프라인 100%

- **Citation Support Rate** = 근거 span이 코퍼스 원문에 실재하는 주장 비율. 사람 표본 검증 100건.
- **Unverified Isolation Rate** = 근거 없어 자동 격리된 주장 비율. **은폐하지 않고 지표화**(K4 방어).
- **DPR (Decision Path Reproducibility)** = 동일 시드 3회 실행 → 결정 DAG 해시 일치율(목표 100%) / 다른 시드 → 결정 일치율(비결정성의 정직한 정량화).
- **cost-of-pass** = 발행 조항 1건당 원. 조항당 토큰·도구호출·wall-clock. 토큰 예산 50/75/100% 조건의 성능 열화 곡선 AUC.
- 궤적 지표: 도구 호출 정확도, 라운드 수, 루프 반복률, 오류 회복률, 재기각률.

### 6.3 1쪽 설계 (상호평가 30% 전용)

- 상단: 헤더표(선택분야/팀명/에이전트명/키워드) + 훅 질문 **"이 프로토콜의 조항 중, 이 분자 때문에 들어간 것은 몇 개입니까?"** + 4문장 요약
- 중단 좌: **먹줄 그림** — 하나의 수직선 [SMILES, 염기성 아민 빨간 표시] → [hERG 위험] → ["12-lead ECG + QTcF>500ms 중단규칙"] → [ICH E14 §근거] → [프로토콜 수정 회피 US$141,000]. 되돌아가는 화살표 4개는 붉게. 결정론=청색/LLM=회색.
- 중단 우: **대비 그림(f2 이식)** — 같은 물성, 구조 알림만 파괴한 decoy 분자. "이 분자에서는 같은 조항이 나오지 않습니다. 그래서 그 조항은 이 분자 때문입니다." Δ\* 값 병기.
- 하단: **실측 4행 표** (룰 32중 K채택 / ΔP@C / FOR_safety / DPR 3-of-3) + 재현 한 줄.
- 본문 텍스트 12줄 이내. 페이지당 텍스트 점유 55~65%.

**앵커링 박스(규제 특화 5문항, peer 권고 이식)** — 3쪽 하단:
> 좋은 규제·임상 설계 에이전트를 판별하는 5가지 질문
> ① 이 조항의 근거 문서와 조·항이 명시되어 있는가 ② 근거가 본문인가 부록인가 Q&A인가 ③ **이 조항이 표준 템플릿에 이미 있는가** ④ 이 조항이 국내 등록 가능 환자를 몇 % 깎는가 ⑤ 근거가 없을 때 시스템이 침묵하는가
> — 이 다섯은 먹줄만 답할 수 있다.

| **W3** | 평가 전량: E1(확장) + E2 + E3 + E4 + **시점절단 홀드아웃**(2025-01 이후 등록 시험) + ablation 5행 + 캘리브레이션(ECE·isotonic) + cost-of-pass Pareto + **3인 사용자 스터디**(먹줄 보조 vs 미보조 조건의 조항 검토 시간·발견 조항 수, TrialGPT 방식) | 베이스라인 우선순위 B-TPL > B-HUMAN > B-RULE > B-LLM1 > B-REACT. E1 규모 축소 시 CI 확대 보고 |
| **W4** | **3막 시연 리허설** + COU 카드·감사 DAG 자동 생성 + 재현 패키지 공개(평가셋 구성 스크립트·스코어러·프롬프트·시드) | 라이브 시연 실패 시 녹화 + 봉인 해시 검증을 현장 재실행하는 대체 각본 |

**본선 시연 3막 각본 (항목6, 예선 문서에 미리 각인)**
- **1막 정상:** 실제 1상 프로토콜 v1과 그 약물 SMILES 투입 → 구조 알림에서 조항 3개 도출 → 각각에 근거 span 결박 → 이 중 2개가 실제 v2에서 추가되었음을 diff로 대조.
- **2막 함정:** 심사위원이 라이브로 (i) 근거 없는 리스크 주입 → **"근거 불충분, 인간 판단 필요"로 기권** (ii) 물성만 같고 알림 파괴한 decoy 분자 투입 → **Δ\*≤0으로 같은 조항이 발행되지 않음** (iii) FDA vs 식약처 상충 케이스 → HITL 에스컬레이션.
- **3막 자기 규율:** 토큰 예산 40%로 제한 → 탐색 폭 축소 후 **우아한 정지 + 미완 항목 명시**. 이어서 우리가 사후에 판정 기준을 완화 → **봉인 해시 불일치로 사이클 무효화.** "우리 시스템은 우리 자신도 속이지 못한다."
- 340개 성공 데모 사이에서 **유일하게 지는 장면을 보여주는 각본.**

## 9. 파급효과 정량 추정

**원칙:** 외부 시장 규모 통계를 쓰지 않는다. 검증된 단가 × 우리 실측 개수만 계산하고, 추정에는 산출 논리를 병기한다. 환율 1 USD = 1,400원 가정 명시.

### 9.1 [실측 기반] 분자 특이 조항의 실제 비율

우리 실측(n=5,208): 조항 유형별 기저율에서 **간기능 52.1%·피임 47.8%는 템플릿**, **QT/ECG 18.4%·CYP/DDI 10.9%는 분자 의존적**. 즉 **프로토콜 조항 중 실제로 분자 판단이 필요한 구간이 존재하며 그 크기가 측정 가능하다.** 먹줄의 가치 주장은 이 구간에만 걸린다.

### 9.2 [조건부] 회피 가능한 프로토콜 수정 비용

- 검증 단가: 실질적 amendment 1건 직접비 중앙값 **2상 $141,000(≈1.97억원) / 3상 $535,000(≈7.49억원)** (Tufts CSDD, Springer TIRS).
- **주장 형식(중요):** "먹줄이 amendment N건을 막아 X억을 절감한다"고 쓰지 않는다. 대신
  > **Cost-Weighted Recall** = Σ_{c ∈ 우리가 발행한 분자 특이 조항 ∩ 실제 프로토콜에 존재} w(c) − Σ_{c ∈ FOR_safety 오류} w(c)
  > 여기서 w(c)는 사용자가 대입하는 조항 유형별 하류 원가이며, 기본값 상한을 $141K/$535K로 둔다.
- 즉 **절감액이 마케팅 문구가 아니라 평가 지표의 출력**이고, 상수는 심사위원·기업이 자기 값을 대입한다. *(K3 방어)*
- **조건:** FOR_safety ≤ 2%가 성립할 때만 유효. 초과 시 절감 주장을 철회한다고 제안서에 명기.

### 9.3 [추정, 산출 논리 공개] 검토 시간

- 현행: 조항 200~400개 × 근거 확인·필요성 판단 3분 = **10~20시간/라운드**, 라운드 3~5회. (우리 추정, 공개 통계 아님)
- 먹줄 적용: 사람이 보는 것은 **① 발행 조항(신뢰도 τ 이상) ② 에스컬레이션 조항 ③ 기권 사유**뿐. 커버리지 목표 25~35% → 검토 대상 조항 50~140개.
- **라운드당 6~14시간 절감(추정 60~70% 단축), 프로그램당(4라운드) 24~56시간.**
- **본선 W3에서 3인 사용자 스터디로 실측 대체.** 그때까지는 추정임을 명시.

### 9.4 [실측] 리소스 효율

E1 전수 처리(분자 10,000 × 조항 12종 × decoy 8)가 **GPU 0장, 외부 API 0회, 단일 CPU 컨테이너 40분 이내**에 완료. 본선 루브릭 '리소스 활용 효율성 15점'에 대한 직접 증거. LLM 토큰은 텍스트 추출·모순 탐지·기권 판단에만 쓰이므로 조항당 토큰이 구조적으로 작다.

### 9.5 [정성] 사회적 가치

- **국내 배포 현실 대응:** AI 전담 인력 0명, 폐쇄망 환경의 중소 바이오텍이 그대로 돌릴 수 있는 hermetic 패키지. RA 인력난은 대형사보다 중소기업이 크게 체감(medicaltimes ID=1140186), 임상약리는 빅파마 100명 대 국내 부족(hitnews 34260).
- **모집난 직격:** ACTUARY의 모집 게이트가 겨냥하는 지표는 screen failure율. 기관 59%가 적격환자 확보 차질, 52%가 의뢰환자 20%+ 사전 부적격(kpanews 538627).
- **규제 공백 충전:** 식약처가 2026년 AI 심사를 도입하고 FDA가 COU 기반 credibility를 요구하는 시점에, **비결정적 멀티에이전트의 재현성을 숫자(DPR)로 낸 규제 산출물**은 국내 최초일 개연성이 있다.
- **공공재:** E1 라벨러·조항 유형 정의·Δ\* decoy 생성기·평가 하네스·룰 채택표를 GitHub 공개. 주최(복지부·진흥원·제약바이오협회) 관점에서 대회 이후에도 남는 자산.

### 9.6 도입 경로 3단계

| 단계 | 내용 | 진입 조건 |
|---|---|---|
| 1 | 사내 파일럿 (기존 프로토콜 회고 검토) | FOR_safety ≤ 2%, DPR 100% |
| 2 | 진행 중 프로그램 적용 (조항 초안 보조) | B-HUMAN 대비 열위 아님, 3개월 회고 검증 |
| 3 | 플랫폼화 (조직 자체 프로토콜 이력으로 재캘리브레이션) | 조직 데이터로 τ 재보정 가능 |

**확장성:** 다른 모달리티·질환으로 옮길 때 바꾸는 것은 **MARKER의 리스크 룰 어댑터 1개와 적응증군 정의**뿐이다. 조항 유형 12종과 코어(신뢰도·귀속 검정·선택적 발행·감사)는 모달리티 불변.

## 10. 연구윤리·오남용 방지 설계

### 10.1 윤리를 문단이 아니라 메커니즘으로

| 리스크 | 메커니즘 | 측정 지표 |
|---|---|---|
| 인용 환각 | provenance 자료형 강제 — `kind ≠ computed`인데 `url`/`span_id` 없으면 **자동 `unverified` 격리 + 판정 가중치 0** | Citation Support Rate, **Unverified Isolation Rate** |

| 규제 회피 논리 자동 생성 (이중용도) | **안전성 조항 완화 제안은 대체 안전장치를 동반할 때만 발행**, 완화 제안은 전량 HITL 승격. 제3자 파이프라인에 대한 대외 공개 판정 금지 | 완화 제안 HITL 승격률 100% |

| 비결정성 은폐 | DPR(동일 시드 해시 일치 / 다른 시드 결정 일치율)을 **숨기지 않고 정량 보고** | DPR |

### 10.2 "이 에이전트가 하지 않는 것" 5줄 (제안서 중반 배치)

① 규제 승인 판단을 대체하지 않는다 — 산출물은 초안이며 서명 주체는 인간 RA다.
② 비임상 데이터를 생성하지 않는다 — 입력으로만 받는다.
③ 안전성 조항을 스스로 완화하지 않는다 — 완화는 대체 안전장치 + 인간 서명이 있을 때만이다.
④ 미승인 적응증에 대한 임상적 판단을 하지 않는다.
⑤ 근거가 코퍼스 밖이면 주장하지 않는다 — 침묵하고 격리한다.

### 10.3 문서 차원 절차

- **AI 사용 내역 4열 표**: 어느 도구를 / 문서의 어느 부분에 / 무엇을 위해 / 인간이 무엇을 검증했는가.
- **전 참고문헌에 URL·DOI + 확인일자 병기.** 확인 못 한 항목은 삭제하지 않고 **`미검증`으로 표기 유지**(삭제보다 정직성 신호가 강하다).
- **라이선스 표** — 확정된 것만: RDKit BSD-3, PoseBusters BSD-3, Inspect AI MIT, Langfuse MIT, Boltz-2 MIT, AiZynthFinder MIT, DSPy MIT, smolagents Apache-2.0, AutoDock Vina Apache-2.0, STRING CC BY 4.0, Human Protein Atlas CC BY 4.0, BindingDB CC BY-SA 3.0. **Arize Phoenix는 라이선스 정보가 상충(Elastic License 2.0 가능성)하므로 사용하지 않는다.** Open Babel은 GPL-2.0이므로 배포 경로에서 제외.
- **실패 카탈로그 3건 공개** (실행 중 발생한 실제 실패로 대체하되, 현재 예상):
  - F1: BRENK 알림 과다 발화로 프로토콜당 경고 30개 초과 → alert budget k=5 도입, precision@5 병기.
  - F2: **반응성 대사체 알림 → 간기능 조항 lift 1.18이 종양 층 내에서 1.02로 소멸** → 적응증 층화를 룰 채택 기준에 필수 편입. *(오늘 실제로 발생한 실패)*
  - F3: 항체 입력에 소분자 룰 오적용 → modality gate 추가, 범위 외 자동 선언.
