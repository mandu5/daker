# 먹줄 INKLINE

분자 구조에서 임상시험 선정·제외기준 조항을 끌어내되, 근거가 확인되지 않으면 조항을 내지 않고 기권하는 에이전트.

> **초안 (2026-09-26).** 링크를 밖에 걸기 전에 맨 아래 [외부에 알리기 전 확인할 것](#외부에-알리기-전-확인할-것)을 먼저 본다.

제4회 AI 신약개발 경진대회 JUMP AI 2026 예선 제안서를 위해 1인으로 만든 저장소다.
분야 3 "규제 대응 및 지능형 임상 설계"에 해당한다.

## 무엇을 했나

바이오텍은 임상 프로토콜을 비슷한 시험의 템플릿에서 복제해 쓰는 일이 많다.
그러면 이 분자 때문에 필요한 제외기준이 빠지고, 나중에 프로토콜 수정 비용으로 돌아온다.

먹줄은 분자 구조를 SMILES로 받아 조항을 제안하면서 세 가지를 지킨다.

1. 템플릿에 원래 있는 조항과 이 분자 때문에 필요한 조항을 실제 임상시험 데이터로 나눈다.
2. 구조 경보가 조항을 내려면, 결과를 보기 전에 선언한 기전 가설이 데이터에서 확인돼야 한다.
3. 목표 정밀도를 넘는 임계값이 없거나 구조가 원인이라는 증거가 없으면 기권한다.

LLM, GPU, 외부 네트워크 없이 끝까지 돈다. 수치와 판정은 RDKit, scikit-learn, scipy가 낸다.

검증에는 TrialBench를 썼다. ClinicalTrials.gov에 2024-02-16 이전에 등록된 시험을 모은 공개 데이터셋이다.
고유 임상시험 81,786건 가운데 분자 구조와 기준 원문을 갖춘 39,379건을 분석했다.

## 결과

아래 수치는 `prototype/results/`에 있는 2026-07-27 실행 결과다.

### 1. 미리 선언한 기전 가설 26개 중 8개만 확인됐다

"이 구조 경보는 이 조항과 이어진다"는 가설 26개를 결과를 보기 전에 코드로 고정했다.
Fisher 검정과 다중비교 보정, 종양·비종양 층화를 모두 통과해야 확인으로 쳤다.
**8개가 확인됐고 15개가 기각됐다.**

| 구조 경보 | 조항 | lift 전체 | 종양 | 비종양 |
|---|---|---|---|---|
| 친유성 cLogP ≥ 3.7 | 음식·자몽 제한 | 1.91 | 2.49 | 1.77 |
| 방향족 할로겐 | 음식·자몽 제한 | 1.89 | 2.48 | 1.71 |
| 방향족 할로겐 | CYP·약물상호작용 | 1.84 | 2.10 | 1.63 |
| 친유성 cLogP ≥ 3.7 | CYP·약물상호작용 | 1.81 | 1.97 | 1.54 |
| hERG 약리단 | QT·심전도 | 1.62 | 1.46 | 1.72 |
| 카복실산 | 위장관 궤양 병력 | 1.54 | 1.15 | 1.85 |
| 염기성 아민 | QT·심전도 | 1.52 | 1.60 | 1.57 |
| 하이드라진 | 간기능 | 1.39 | 1.26 | 1.56 |

기각된 것 중 세 건은 반대 방향으로 유의했다. 교과서적 경보인 티오펜 → 간독성은 lift 0.57, p = 8.9e-28이었다.
교과서의 구조 경보를 검증 없이 조항으로 옮기면 안 된다는 뜻이고, 그래서 확인된 기전만 조항을 낼 수 있게 설계했다.

### 2. 조항 라벨러를 스스로 감사했다

정답 라벨은 정규식으로 붙인 근사치다. 이를 한계로 적어 두는 데서 멈추지 않고, 양성 표본을 원문과 하나씩 대조했다.

| | 결함 | 규모 |
|---|---|---|
| D1 | "12-lead ECG will be performed" 같은 검사 일정 서술을 QT 조항으로 셈 | QT 양성의 61.2% |
| D2 | `grapefruit`이 음식효과와 CYP 양쪽에 있어 같은 신호를 두 번 셈 | 음식효과 양성의 97.2%가 겹침 |
| D3 | 대소문자를 무시해 신기능 지표 eGFR이 폐암 표적 EGFR을 잡음 | 신기능 양성 877건 |
| D4 | `hemoglobin`이 당뇨 지표 HbA1c를 잡음 | 혈액 양성 588건 |

D1과 D2를 고치자 지표가 모두 좋아졌다.
실제로 있는 안전성 조항을 불필요하다고 판정한 비율은 **1.08%에서 0.12%로** 내려갔다.
QT 조항의 정밀도 향상은 유의하지 않던 1.09배에서 **2.93배**가 됐다.
감사 전에는 기전으로 설명되지 않는 쪽이 오히려 더 잘 맞는 것처럼 보였는데, 그 역전은 현상이 아니라 라벨 잡음이었다.
D3과 D4를 고친 뒤에도 확인된 가설 8개는 그대로였다.

**고치지 못한 것도 남겼다.** 간·신·혈액 조항 양성의 15~18%는 임계값 없는 검사 항목 나열이다.
정규식을 좁히는 방식을 두 번 시도했지만 둘 다 기저율을 오히려 올리고 진짜 조항을 떨어뜨렸다.
사람이 정답 집합을 만들고 평가자 간 일치도를 재기 전에는 손대지 않는다.
전체 기록은 [docs/05-labeler-audit.md](docs/05-labeler-audit.md)에 있다.

### 3. 발행과 기권

| 지표 | 값 |
|---|---|
| 안전성 조항 누락률 | 0.12%, 95% 구간 0.02~0.67%. 목표 2% 이하 |
| 음성 대조 누출 | 6,748쌍 중 0건 |
| 발행한 조항의 정밀도 | 0.301, 73건 발행 |
| CYP·약물상호작용 정밀도 | 조항 기저율의 3.56배 |
| 기권율 | 91.7% |
| 감사 기록 재현성 | 3회 실행의 해시 일치 |

대부분 기권한다. 근거가 모자라면 말하지 않는 쪽을 택했고, 기권한 만큼 실무자가 검토할 조항이 줄어든다.

## 재현 방법

2026-07 실행 환경: Python 3.11, RDKit 2026.03.4, scikit-learn 1.9.0, scipy 1.17.1, numpy.

```bash
pip install numpy scipy scikit-learn rdkit

prototype/trialbench/fetch.sh                  # TrialBench 내려받기, 약 1GB, ~/.cache/trialbench
python3 prototype/trialbench/s2c_analysis.py   # 기전 가설 게이트 → results/s2c_associations.json
prototype/rerun.sh                             # 템플릿 대비 증분 → 조항별 임계 보정 → 기권·오판 → 안전 불변식

# 분자 하나를 끝까지 돌려 보기
python3 prototype/inkline/run.py --smiles "CC(=O)Oc1ccccc1C(=O)O" \
    --phase "Phase 2" --indication "hypertension" --noael 100 --repeat 3
```

라벨을 고쳤다면 `s2c_analysis.py`부터 다시 돌린다. 중간 단계 하나만 다시 돌리면 결과 JSON 사이가 어긋난다.
제안서 빌드는 [proposal/README.md](proposal/README.md)를 본다.
