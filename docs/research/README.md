| 단계 | 에이전트 수 | 산출물 |

| Recon | 5 | 역대 대회 경향 / 에이전틱 신약개발 SOTA·미해결 gap / 사용 가능한 툴체인·데이터 / 루브릭·Peer Review 최적화 / 경쟁 화이트스페이스 |

## 이 자료를 그대로 믿지 않는다

`final_charter.md` 는 서브에이전트의 산출물이며 **검증 전 자료**다.
독립 검증 결과는 `../02-concept-decision.md` 에 기록했다. 요약하면:

- 실측 수치는 **재현됨** (n=5,208, lift·p값 일치)
- 참고문헌 4건 **실재 확인**
